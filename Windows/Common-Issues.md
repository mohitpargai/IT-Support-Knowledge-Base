# Common Windows Issues

## 1. Slow System

**Checks**
- Open Task Manager with `Ctrl + Shift + Esc`.
- Review CPU, Memory, Disk, and Network usage.
- Check available disk space.
- Review startup applications and recent updates.
- Check Reliability Monitor for recurring failures.

**Resolution**
- Close unnecessary applications after confirming they are not required.
- Apply approved updates.
- Escalate suspected hardware or storage faults.

## 2. Application Not Responding

**Checks**
- Confirm whether the issue affects one application or multiple applications.
- Record the exact error message and time.
- Check Task Manager for application resource usage.
- Review Event Viewer application logs.

**Resolution**
- Save work where possible.
- Restart the application only after checking for unsaved work and user impact.
- Escalate recurring crashes with logs and reproduction steps.

## 3. Remote Desktop Connection Failure

**Checks**
- Confirm the target hostname and user authorization.
- Test network reachability.
- Confirm Remote Desktop is enabled according to policy.
- Check VPN, firewall, and access-control requirements.

Do not weaken firewall or security policies to bypass a connection problem.
