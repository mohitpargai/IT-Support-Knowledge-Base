# Application Not Opening

## Information to Collect
- Application name and version.
- Operating system and device.
- Exact error text or screenshot with sensitive data removed.
- Time the issue started.
- Whether other users are affected.
- Recent updates, deployments, or configuration changes.

## Troubleshooting
1. Confirm the application is installed and the user is authorized.
2. Check whether the required service and dependencies are available.
3. Review relevant application and system logs.
4. Check network connectivity to required endpoints.
5. Check disk space and available memory.
6. Follow the approved process for restarting or repairing the application.
7. Validate login and the user's primary workflow.

Do not reinstall software or delete application data before checking data retention, configuration, and business impact.
