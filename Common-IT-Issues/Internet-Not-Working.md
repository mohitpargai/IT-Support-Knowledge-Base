# Internet Not Working

## Initial Checks
1. Confirm whether one device or multiple devices are affected.
2. Check Wi-Fi/Ethernet status and physical connections.
3. Confirm IP address, gateway, and DNS settings.
4. Test gateway reachability.
5. Test an approved external IP and then a hostname.
6. Check VPN, proxy, and organizational network restrictions.
7. Check for known ISP or network incidents.

## Useful Commands
- **Windows:** `ipconfig /all`, `ping <gateway>`, `nslookup example.com`
- **Linux:** `ip addr`, `ip route`, `getent hosts example.com`

## Resolution and Validation
Apply only approved changes. Confirm that the user can access the required business applications and record the outcome.
